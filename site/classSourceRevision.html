Detailed Description

The commit a source tree (Chaste itself, or a checked out project) was built from, and whether it had uncommitted changes at the time. See ChasteBuildInfo::GetChasteRevision() and ChasteBuildInfo::GetProjectRevisions().

std::string SourceRevision::GetShortCommit ( ) const
Returns
the commit hash shortened for display to its first SHORT_COMMIT_LENGTH characters, or "unknown" if it could not be determined. This is a fixed length, rather than the shortest unambiguous one, so that a commit always displays the same way wherever it was built.
